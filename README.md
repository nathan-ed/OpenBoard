# Screenshots: straighten lines and shapes when holding the pen still

Images used in the description of the OpenBoard pull request
"feat: straighten lines and shapes when holding the pen still"
(branch `feat-straighten-shapes-on-hold`, refs OpenBoard-org/OpenBoard#1564).

All images were captured from OpenBoard built from that branch (Linux, Qt 6.4).

| File | Content |
|---|---|
| `straighten-shapes-on-hold/demo-drawing-shapes-and-handwriting.gif` | Shapes drawn freehand and straightened after a short hold; handwriting and a rectangle drawn without a pause stay unchanged |
| `straighten-shapes-on-hold/same-strokes-option-off-vs-on.png` | The same strokes with the option off (freehand) and on (straightened) |
| `straighten-shapes-on-hold/marker-circle-rectangle-triangle.png` | Shapes drawn with the marker, keeping its transparency |
| `straighten-shapes-on-hold/preferences-pen-tab-option-enabled.png` | The new option in Preferences → Pen |

This branch only hosts images and is not meant to be merged.
